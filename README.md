# Hermes Onboarding Template

Este repositório contém dados pré-configurados para fazer onboarding rápido em novas instalações do Hermes Agent.

## Como usar

1. Clone o repositório
2. Diga para o Hermes:
   "fazer onboarding conforme repo ~/Documents/GitHub/hermes-onboarding-template"
3. O agente vai ler os arquivos e aplicar as configurações automaticamente

## Estrutura

- `user-profile.md` → Informações do usuário (nome, cargo, experiência, contato, destaques)
- `toolsets.md` → Toolsets recomendados
- `skills.md` → Skills a instalar
- `config-snippets/` → Configurações de exemplo
- `multi-model-strategy.md` → Estratégia de uso de múltiplos modelos
- `security.md` → Recomendações de segurança e approvals
- `setup-verification.md` → Verificação do que ainda não está configurado
- `agent-persona.md` → Define como o agente deve se comportar (inclui pergunta pelo nome do agente)
- `rules.md` → Regras específicas de comunicação e restrições
