# Hermes Onboarding Template

Este repositório contém dados pré-configurados para fazer onboarding rápido em novas instalações do Hermes Agent.

## Como usar

1. Clone o repositório
2. Diga para o Hermes:
   "fazer onboarding conforme repo ~/Documents/GitHub/hermes-onboarding-template"
3. O agente vai ler os arquivos e popular os arquivos oficiais do Hermes (`SOUL.md`, `USER.md`, `MEMORY.md`)

## Estrutura

- `user-profile.md` → Fonte de dados para `USER.md`
- `agent-persona.md` + `rules.md` → Fonte de dados para `SOUL.md`
- `multi-model-strategy.md` → Parte da estratégia que vai para `MEMORY.md`
- `security.md` → Recomendações de segurança
- `setup-verification.md` → Verificação + instruções para popular arquivos oficiais
- `toolsets.md` → Toolsets recomendados
- `skills.md` → Skills a instalar
- `config-snippets/` → Configurações de exemplo
